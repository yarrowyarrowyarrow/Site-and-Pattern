# Plans

One file per increment, written before the work and kept with it.

A plan here is not a status report — it is the **reasoning** behind a release:
what was actually wrong, what was measured, what was decided and why, and what
was deliberately left alone. The commit log says what changed; this says what we
believed at the time. When a later session asks "why is it like this?", the
answer should be findable without reconstructing it from diffs.

## Naming

```
docs/plans/V<major>.<minor>-<short-slug>.md
```

Version first, matching the release-branch convention in
[`CLAUDE.md`](../../CLAUDE.md), so plans sort in release order and a plan is
obviously paired with the branch that carried it out.

## Writing one

- **Lead with the evidence.** Numbers where there are numbers. "moist_mixedgrass
  is on 246 plants and aspen_parkland on 136" is worth more than "the ecoregion
  tags look wrong".
- **Say what you could not verify**, and why. A constraint recorded once saves
  the next session rediscovering it.
- **Record corrections in place.** When investigation falsifies part of the
  plan, amend it and say so — a plan that only ever describes what turned out to
  be true is a plan nobody can learn from.
- **Name what is not being done**, so the omission reads as a decision rather
  than an oversight.

| V2.48 | [the-colour-was-a-guess](V2.48-the-colour-was-a-guess.md) | Four reports on V2.47: flower colour sourced per genus ("you have blue and yellow columbine as red"), no colour filter in the plant tab, a website searchable on four axes out of sixty-eight columns, and a request for ecoregion maps, a higher-end look and no em dashes | Shipped. The colour bug was not introduced by V2.47, it was *revealed* by it: the column had always been a genus-level guess correctly labelled `estimated` in a field nothing displayed, and 32 genera shared one hex. With no flora reachable, 36 species were corrected against evidence that travels with them (Latin epithet, accepted common name) and the other 359 are now marked *not verified* rather than silently estimated. Five audit trips were left alone on purpose and carry their reasons, because a colour word in a name usually describes the berry. Drawing the range maps exposed a separate bug: three duplicated scientific names meant one row of each pair silently lost its GBIF ranges. 23 facets replaced 4; `medicinal` is excluded from the public role vocabulary for the same P12 reason the notes are. |
| V2.47 | [colour-and-a-public-catalogue](V2.47-colour-and-a-public-catalogue.md) | Two gaps a competitor read turned up: no flower-colour filter despite holding the hex since schema v31, and the F90 plant directory locked inside a desktop installer | Shipped. The data made the design: only 23 distinct hexes are in use, and the largest bucket (79 rows of `#cbbd80`) turned out to be *every* grass, sedge and rush — the wind-pollinated default, not a colour, so it got a bucket that says so rather than being filed under yellow. The site build swept all 439 species through `species_entry` and found a `ValueError` that had made one species' page unopenable in the desktop directory since F90. P12 forced a real decision: ~43 `notes` rows describe traditional medicinal use, and publishing to the open web is not the same act as showing it in a panel, so notes are withheld by default. The competitor itself was never reachable — egress policy — so the comparison rests on search indexing of their own pages. |
| V2.46 | [life-size-and-a-net-in-his-hand](V2.46-life-size-and-a-net-in-his-hand.md) | Five reports from watching V2.45's animals fly: a butterfly beat that is *"too fast and unnatural"*, creature sizes that are *"all wrong"* against the walker, no editing in the 3D preview, creatures passing through trees and buildings, and generic sprites | Shipped, except the sprite painting — the bench the author remembered (`scripts/tune_fauna.py`, bee band colours and all) already exists, and the part that does not is a wing-texture pipeline against GLBs that ship with no UVs by contract, so it is scoped rather than squeezed in. The scale error was 6–39×, and the author's own aside named the evidence: the calligrapher fly read "more correctly" because at 15 mm its wrongness happened to land closest to plausible. Two independent causes behind one flapping complaint — butterflies were using a *crow's* bout, and `beatGain` never stopped the wings at all, it shrank them to a 22% tremble at full rate. The guard fired for the third increment running and named its own seam again. |

Birds were the only flying taxon with no morphology table at all. No network this session, so all 24 rows ship unverified and say so. |
| V2.44 | [the-sandbox-becomes-a-place-you-can-work](V2.44-the-sandbox-becomes-a-place-you-can-work.md) | Four things walking the V2.43 sandbox exposed: walk controls that did not match the 3D preview, no animation on any edit, a new plant appearing full-grown among its neighbours, and no split-screen map+3D | Shipped.
